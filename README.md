# Bulwark

A browser base-defence game in the spirit of Defense Grid. The player mines raw materials, carries them on conveyors to factories that make parts, stockpiles the parts and spends them on defences. Skill trees unlock better factories and defences. Attackers arrive in predetermined waves.

Setting: a sci-fi colony outpost on a hostile planet. All art is drawn from code (vector shapes, shaders, procedural effects).

Planning stage. Decisions are tracked in the Obsidian vault note `Projects/Base Defence Game — Wayfinder Map.md`.
